Questions

Do I have to trust you with my DNS API keys?

No. The agent runs on your own standby server and talks to your DNS provider directly. Credentials are stored locally and never sent to us. The agent is open source (AGPL-3.0) — you can read every line.

What if GuardUp's servers go down?

Your protection keeps working. The failover logic and state machine run entirely in the agent on your server. A hosted control plane, if you use it, only handles configuration, alerts, and reports — it is not in the critical path.

How fast is failover?

Typically 1–10 minutes, dominated by your DNS record's TTL. We check every 60s by default, require 2 consecutive failures, then change DNS. Free tiers of some providers enforce a 600s TTL minimum.

Which DNS providers are supported?

Cloudflare, Aliyun DNS, DNSPod (v1), and Tencent Cloud DNS. The wizard auto-detects which one you use.

Why open source if it's a paid product?

Because handing a tool automatic control of your DNS requires trust, and open source is how you earn it. The hosted control plane, multi-region confirmation, and alerting are the paid part — the agent itself is free and auditable. This is the same open-core model GitLab and Grafana use.
